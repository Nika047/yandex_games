# Marble Sort

Казуальная головоломка для Яндекс Игр в духе Pixel Flow: коробки с шариками ездят по ленте под картинкой и закрашивают её.

## Правила

- Сверху картинка из цветных клеток. Закрашивается она **снизу вверх по столбцам**: стрелять можно только в нижнюю незакрашенную клетку столбца (на ней белое кольцо), и только шариком её цвета.
- Под картинкой лента-прямоугольник. По ней по кругу едут места для коробок (тёмные квадраты, их число - вместимость ленты). Вместимость показана сразу, даже когда лента пуста.
- Внизу очереди коробок. В каждой коробке цвет и число шариков. Видны первые 3 коробки каждой очереди, дальше написано «ещё N».
- Нажатие на очередь ставит её первую коробку на свободное место ленты. Когда коробка проезжает под столбцом, она стреляет вверх: если нижняя клетка столбца её цвета, клетка закрашивается и в коробке становится на шарик меньше. Пустая коробка уходит с ленты.
- Коробка, цвет которой сейчас никому не нужен, едет по кругу и занимает место на ленте, пока цвет не понадобится. Поэтому выбирать нужно коробки, которые смогут стрелять.
- Победа: картинка закрашена. Поражение: лента занята, и ни одна коробка на ней не может выстрелить.

## Экраны

- **Выбор уровня** (первый экран): карточки всех уровней с миниатюрой картинки, номером, числом клеток и размером ленты. Пройденные отмечены галочкой. Доступны все уровни сразу, чтобы можно было проверять сложность.
- **Игра**: кнопки «Уровни» (в меню) и «Заново». После победы «Дальше» открывает следующий уровень, на последнем «К уровням». После поражения «Ещё раз» и «К уровням».

## Управление

| Действие | Мышь / палец | Клавиатура (ПК) |
|---|---|---|
| Выбрать очередь | - | стрелки или WASD (влево/вверх/A/W - назад, вправо/вниз/D/S - вперёд, пустые очереди пропускаются) |
| Отправить коробку на ленту | нажатие на очередь | Enter |
| Кнопка в окне победы и поражения | нажатие | Enter (главная кнопка) |
| Выбор уровня в меню | нажатие на карточку | стрелки или WASD листают карточки, Enter открывает |
| Вернуться в меню уровней | кнопка «Уровни» | Esc |

Выбранная очередь обведена золотой рамкой. Подсказки про клавиши видны только на десктопе.

## Запуск

```bash
npm install
npm run dev
```

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер Vite (по умолчанию http://localhost:5173) |
| `npm run build` | проверка типов и сборка в `dist/` (пути относительные, `base: './'`) |
| `npm run typecheck` | только проверка типов |
| `npm run simulate` | прогон всех уровней ботами, показывает доли побед и время создания уровня |

## Состав

| Путь | Назначение |

| `src/MenuScene.ts` | экран выбора уровня: сетка карточек, миниатюры, мышь и клавиатура, прокрутка, если уровней больше, чем помещается |
| `src/GameScene.ts` | игровой экран: картинка, лента, очереди, анимации, окна победы и поражения |
| `src/ui.ts` | общее оформление: размеры экрана, фон-градиент, скруглённые панели, кнопки |
| `src/progress.ts` | прогресс в `localStorage`: последний уровень и пройденные |
| `src/main.ts` | запуск Phaser, масштаб FIT, логический размер 540x960 |
| `scripts/simulate.ts` | проверка проходимости и сложности уровней ботами |
| `scripts/image-to-level.ps1` | перевод своей картинки в схему пикселей палитры игры |

Стек: Phaser 4, TypeScript 7, Vite 8. Графика целиком из кругов, прямоугольников и скруглённых прямоугольников Phaser, внешних ассетов нет. `scripts/simulate.ts` запускается Node с вырезанием типов, поэтому в `src/logic.ts`, `src/levels.ts` и `src/pictures.ts` нельзя использовать синтаксис, который не только типы (параметры-свойства конструктора, `enum`).

Сцены Phaser запускаются заново при каждом входе, поэтому обработчики клавиш в `GameScene` и `MenuScene` снимаются в событии `shutdown`. Без этого они копятся и каждое нажатие срабатывает несколько раз.

## Как устроена лента

Все места ленты едут вместе, на равном расстоянии. Круг ленты - `2 * ширина + 2 * BELT_ROWS - 4` позиций (`BELT_ROWS = 4`): сначала верхняя сторона над столбцами картинки слева направо (позиция равна номеру столбца), потом вниз по правой стороне, налево по нижней и вверх по левой. Шаг `Game.tick()`: коробки на верхней стороне стреляют по своему столбцу, потом лента едет на одну позицию. В игре шаг идёт по таймеру (`TICK_MS` в `GameScene.ts`), в скрипте проверки - подряд (`Game.settle()`). Исход партии от скорости ленты не зависит, зависит только от порядка, в котором игрок ставит коробки.

## Как усложнять

В `Difficulty` (`src/logic.ts`) уже есть параметры, которые отвечают за сложность; новые задумки (скрывать следующие коробки, связывать коробки) добавляются сюда же и в `buildQueues`:

| Параметр | Что значит | По умолчанию |
|---|---|---|
| `queues` | число очередей | 4 |
| `belt` | вместимость ленты | 5 |
| `minBox`, `maxBox` | сколько шариков в коробке | 4 и 8 |
| `depth` | сколько коробок в очереди видно (остальные скрыты, видно только их число) | 3 |
| `chunk` | размер куска очереди, внутри которого коробки перемешаны (0 - строго в порядке решения) | 6 |

Очереди строит `buildQueues`: сначала порядок решения (случайный столбец называет цвет, коробка этого цвета «стреляет» по всем столбцам, которым цвет нужен), потом перемешивание кусками по `chunk` и раздача по очередям по кругу. Чем больше кусок и чем меньше лента, тем сложнее.

**Гарантия проходимости.** `createGame` берёт первую очередь, которую проходит жадная стратегия (`greedyPick`: ставить коробку, цвет которой нужен сейчас, и лучше ту, что опустеет сразу; если нужной нет, самую маленькую). Жадная видит только первые коробки очередей, так что уровень всегда проходим простой разумной игрой, а ошибки наказываются. Если за 200 попыток жадная не прошла, берётся исходная очередь.

## Как добавить уровень

1. В `src/levels.ts` добавить объект в `LEVELS`: `name`, `rows` (строки одной длины, буквы из `COLOR_KEYS`, точка - пусто) и при необходимости `difficulty`. Неверная длина строки или незнакомая буква дают исключение при старте уровня.
2. Картинку можно нарисовать в `src/pictures.ts` из примитивов `Canvas` или перевести готовую:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/image-to-level.ps1 -Path C:\pics\cat.png -Width 24 -Name "Мой кот"
```

Скрипт заменяет каждый пиксель ближайшим цветом палитры (цвета читаются из `src/levels.ts`, прозрачные пиксели становятся пустыми), печатает готовый блок для `LEVELS` и сохраняет его в `<картинка>.level.txt`. Ключ `-Only "rpygbwk"` ограничивает набор цветов. Фотографии лучше брать простые и контрастные, ширина 20-28 клеток.

3. Запустить `npm run simulate` и подобрать `belt` и `chunk`: случайный бот должен проигрывать, жадный на очереди игрока проходить всё.

## Состояние и известные ограничения

- Правила менялись три раза: картинка из шариков, которые кладутся сами (исход не зависел от игрока); коробки и слоты; лента с очередями (текущая). Подробности про первые две версии потеряны, они сохранены только в истории разговора.
- Картинки нарисованы кодом из примитивов (`src/pictures.ts`), они простые и местами угловатые («Лес ночью», «Море»). Лучше заменить своими, пропущенными через `scripts/image-to-level.ps1`.
- Обучение на первом уровне: три коротких подсказки по первым ходам (`TUTORIAL_HINTS` в `GameScene.ts`, флаг `marble-sort-tutorial` в `localStorage`). Первые две подсказки проверены в браузере, третья и завершение обучения нет.
- Нет звука, SDK Яндекс Игр и рекламы. Все 16 уровней открыты сразу (так задумано для проверки сложности), для публикации нужны порядок прохождения и блокировка.
- Скрытие следующих коробок (`depth`) уже управляет видимостью очередей, но «связанные» коробки не сделаны.
- Только вертикальная раскладка 540x960: на широком экране игра масштабируется по высоте (FIT), по бокам остаётся фон. На телефонном размере новую раскладку не смотрела.
- Сборка около 1,4 МБ (364 КБ в сжатом виде, почти весь Phaser), лимиты Яндекс Игр не проверялись.
- В скрытой панели браузера страница получает около 6 кадров в секунду, анимации выглядят вялыми, поэтому проверять темп игры нужно в обычном браузере.
- Dev-режим: правка файлов во время партии перезагружает страницу, и в консоли может появиться ошибка таймера уничтоженной сцены. В обычной игре и в сборке этого нет.
